The app auto-detects whether a built Vite SPA exists under `static/`; if not, the root path serves an inline HTML page instructing to run `cd apps/dsa-web && npm install && npm run build`. CORS can be opened to all origins via `CORS_ALLOW_ALL=true` (warned at startup unless auth is enabled). Runtime scheduler behavior is controlled by environment variables `CLI_SCHEDULER_OWNER_ENV`, `RUNTIME_SCHEDULER_FORCE_ENABLED_ENV`, `RUNTIME_SCHEDULER_SUPPRESS_START_ENV`, `RUNTIME_SCHEDULER_RUN_IMMEDIATELY_ENV`, and `RUNTIME_SCHEDULER_ARGS_ENV`.
