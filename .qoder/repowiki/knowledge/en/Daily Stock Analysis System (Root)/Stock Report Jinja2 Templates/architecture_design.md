The module is a pure presentation layer of four Jinja2 template files. `_macros.j2` defines the reusable `market_snapshot` macro (a table of market snapshot fields) imported by other templates via `{% from '_macros.j2' import market_snapshot with context %}`. Three output-format templates consume the same enriched result payload: `report_brief.j2` produces a compact one-line-per-stock summary; `report_markdown.j2` renders a full dashboard with sections for intelligence, core conclusion, data perspective (MA alignment, price position, volume, chip structure), phase decision, signal attribution, strategy synthesis, battle plan, and history comparison; `report_wechat.j2` emits a truncated, emoji-heavy variant optimized for WeChat message width, including length-capped strings and inline bullet lists. All templates share a common rendering contract — they iterate over an `enriched` list where each entry exposes `e.result`, `e.signal_emoji`, `e.signal_text`, `e.stock_name`, `e.localized_trend_prediction`, and `e.empty_news_disclosure`, plus globals like `labels`, `report_date`, `report_timestamp`, `buy_count/hold_count/sell_count`, `summary_only`, `show_llm_model`, `models_used`, and helper functions (`localize_*`, `normalize_strategy_synthesis_payload`, `strategy_invalid_opinion_count`, `signal_attribution_weight_items`, `get_chip_unavailable_reason`, `clean_sniper`, `failed_checks`). There is no Python code in this scope; templates depend outward on the caller to supply these variables and helpers.
