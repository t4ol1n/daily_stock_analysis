`./scripts/test.sh <scenario>` dispatches end-to-end scenarios against `main.py` (e.g. `./scripts/test.sh us-stock`, `./scripts/test.sh quick`). `./scripts/ci_gate.sh [all|syntax|flake8|deterministic|offline-tests]` runs the full CI pre-check pipeline; offline tests can be split via `PYTEST_SPLITS`/`PYTEST_GROUP` env vars passed through `ci_test_shard.py`. macOS builds require Node/npm for `apps/dsa-web` and PyInstaller installed on the host; `PYTHON_BIN` can override the interpreter. `GITHUB_ACTIONS=true` disables proxy injection in `check_env.py`.
