The `scripts/` directory is a flat collection of standalone tooling with no shared Python package — each file is an independent entry point invoked directly from shell or CI. It groups into four functional areas: (1) Build pipelines — `build-all-macos.sh`, `build-backend-macos.sh`, `build-desktop-macos.sh` (and `.ps1` Windows counterparts) chain npm build of `apps/dsa-web`, then PyInstaller invocation of `main.py` with explicit `--hidden-import`, `--collect-all`, and `--add-data` flags for static assets, strategies, and third-party packages; `pyinstaller_runtime_compat.py` is injected as a runtime hook to disable NLTK's import-security guard in frozen binaries. (2) CI gate — `ci_gate.sh` runs syntax checks (`py_compile`), flake8 critical errors, deterministic unit tests via `test.sh code|yfinance`, and an offline pytest suite that supports sharding through `ci_test_shard.py` using duration hints from `.github/ci-test-durations.json`. (3) Diagnostics & data ops — `check_env.py` validates config, DB, data fetchers, LLM (Gemini), and WeChat notifications; `generate_stock_index.py`, `refresh_stock_index.py`, `generate_index_from_csv.py`, `fetch_tushare_stock_list.py`, `generate_longbridge_oauth_token.py`, `generate_notification_actions_env_table.py` produce or refresh seed data consumed by the app. (4) Test harness — `test.sh` is a CLI dispatcher invoking `python3 main.py` with scenario flags (`market`, `a-stock`, `hk-stock`, `us-stock`, `mixed`, `single`, `dry-run`, `full`, `quick`) plus inline pytest snippets for code recognition and YFinance symbol conversion. Dependency direction is one-way: scripts import from the repo root (`src.*`, `data_provider.*`, `api.*`) but nothing in `src/` imports back into `scripts/`; seeds under `stock_index_seeds/` are plain CSV fixtures consumed by the index generators.
