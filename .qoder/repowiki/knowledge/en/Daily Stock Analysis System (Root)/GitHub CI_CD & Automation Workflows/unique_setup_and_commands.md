Release publishing requires an annotated tag (`git tag -a vX.Y.Z -m '<notes>'`) because `docker-publish.yml` validates that the tag has an annotation message before building images. The CI uses a retry loop (3 attempts, 15s sleep) when installing `.github/requirements-ci.txt` to tolerate transient pip failures. Backend tests are split across 3 shards via `PYTEST_SPLITS=3` and `PYTEST_GROUP`. Desktop packaging jobs require pre-built web assets (`npm ci --prefix apps/dsa-web`) before invoking `scripts/build-backend.ps1` / `scripts/build-backend-macos.sh`.
