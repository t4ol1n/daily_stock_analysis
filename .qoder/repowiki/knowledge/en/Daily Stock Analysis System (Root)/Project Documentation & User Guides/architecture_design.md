Flat collection of Markdown guides plus supporting subdirectories: `architecture/` holds machine-readable specs (OpenAPI JSON), `assets/` stores images, icons, and a Python script to regenerate icon sets, `bot/` contains per-platform bot setup screenshots and markdowns, `docker/` documents platform-specific deployments, and `examples/` provides sample config files. Top-level docs are grouped by audience — quick start (`README_*`, `beginner-client-setup.md`), full configuration (`full-guide*`, `LLM_CONFIG_GUIDE*`, `notifications.md`, `data-source-stability.md`), feature deep-dives (`alerts.md`, `decision-signals.md`, `intelligence-sources.md`, `analysis-context-pack.md`), deployment (`DEPLOY*`, `deploy-webui-cloud.md`, `desktop-package.md`), and developer references (`CONTRIBUTING*`, `CHANGELOG.md`). `INDEX.md` / `INDEX_EN.md` act as the central navigation hub linking all other docs. There is no build step; content is consumed directly by GitHub Pages or rendered alongside the repo.
