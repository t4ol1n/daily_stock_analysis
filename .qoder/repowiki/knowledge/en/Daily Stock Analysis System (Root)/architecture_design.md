The root exposes three executable entry points that all converge on the same `src` package: `main.py` is the primary CLI orchestrator launching the `StockAnalysisPipeline`, scheduled market review, auto-backtest, and optional FastAPI/Web UI via `--serve`/`--webui`; `server.py` is a thin Uvicorn bootstrap that imports `api.app:app` from the `api_server` child; `webui.py` is a convenience wrapper around the same FastAPI app. All entry points call `src.config.setup_env()` and `src.logging_config.setup_logging()` before any domain import, so configuration, environment variables (`.env`), proxy injection, and log routing are shared across CLI, API, and bot processes. The `api_server` child mounts routes against the same pipeline instance that `core_engine`'s `StockAnalysisPipeline` runs, while `chat_bot` consumes the same LLM/data-provider abstractions under `data_providers` and `strategies`. Packaging (`docker_packaging`) builds a single image whose entrypoint invokes these same scripts, and CI (`github_ci`) drives tests in `tests` plus build/gate scripts in `scripts_and_tools`.
