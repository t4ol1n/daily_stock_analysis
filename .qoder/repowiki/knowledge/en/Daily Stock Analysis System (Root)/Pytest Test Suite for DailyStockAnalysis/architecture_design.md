Flat pytest package rooted at `tests/` with a single `agent/` sub-package grouping multi-agent disagreement tests. Shared test infrastructure lives in `conftest.py`, which patches FastAPI/Starlette `TestClient` via a custom `_ThreadlessTestClient` to avoid AnyIO cross-thread portal issues, and monkey-patches `asyncio.BaseEventLoop` hooks so anyio worker queues wake reliably during sandboxed runs. The `litellm_stub.py` module installs a minimal `litellm` types stub into `sys.modules` on demand, letting unit tests import code that depends on LiteLLM without pulling in the heavy library. Tests are organized by feature area (e.g., `test_agent_backend.py`, `test_pipeline_*.py`, `test_*fetcher.py`, `test_notification_*.py`) and target `src/` modules directly rather than through CLI entry points, using `unittest.mock.patch` and `monkeypatch` to isolate subsystems. Fixture assets live under `fixtures/notification_reports/` as Markdown templates consumed by notification/report tests.
