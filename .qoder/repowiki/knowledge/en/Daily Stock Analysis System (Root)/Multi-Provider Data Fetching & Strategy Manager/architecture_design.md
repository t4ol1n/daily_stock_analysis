The module implements the Strategy Pattern around an abstract `BaseFetcher` in `base.py`, which defines the contract `_fetch_raw_data` / `_normalize_data` plus shared daily-data pipeline (`get_daily_data` → clean → compute MA/Volume_Ratio). Each provider is a sibling file (`akshare_fetcher.py`, `tushare_fetcher.py`, `yfinance_fetcher.py`, `longbridge_fetcher.py`, `futu_fetcher.py`, `finnhub_fetcher.py`, `alphavantage_fetcher.py`, `baostock_fetcher.py`, `pytdx_fetcher.py`, `efinance_fetcher.py`, `tencent_fetcher.py`, `tickflow_fetcher.py`, `tw_institutional_fetcher.py`) subclassing `BaseFetcher` and declaring a `priority` for ordering. `DataFetcherManager` in `base.py` orchestrates them: it maintains per-market capability tables (`_DAILY_MARKET_FETCHER_SUPPORT`), ordered fallback chains for CN indices (`_CN_INDEX_DAILY_SOURCE_ORDER`), and a class-level `CircuitBreaker` (`_daily_source_health`) to short-circuit failing sources. Market detection helpers (`_is_us_market`, `_is_hk_market`, `_is_jp_market`, `_is_kr_market`, `_is_tw_market`, `normalize_stock_code`, `canonical_stock_code`) route codes to the right provider. Realtime quotes are normalized via `UnifiedRealtimeQuote` and `ChipDistribution` in `realtime_types.py`, which also hosts the `CircuitBreaker` state machine (CLOSED/OPEN/HALF_OPEN) used by all fetchers. Fundamental data is decoupled into market-specific adapters — `AkshareFundamentalAdapter` (CN), `YfinanceFundamentalAdapter` (HK/US), and `FutuFundamentalAdapter` — aggregated through `DataFetcherManager.get_fundamental_context`. Cross-cutting concerns (rate limiting, jitter sleep, retry with tenacity, user-agent rotation, process timeouts) live inside each fetcher; the manager only handles routing, health, and concurrency locks (`RLock` per fetcher instance).
