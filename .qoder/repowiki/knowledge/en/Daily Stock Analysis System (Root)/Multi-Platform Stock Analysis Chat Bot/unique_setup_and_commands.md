The dispatcher is initialized on first use via `bot.dispatcher.get_dispatcher()`, which reads `bot_command_prefix`, `bot_rate_limit_requests`, `bot_rate_limit_window`, and `bot_admin_users` from `src.config.get_config()` and auto-registers all commands from `bot.commands.ALL_COMMANDS`. Optional stream clients for DingTalk and Feishu are only available when their SDKs are installed; otherwise the imports fail silently and the corresponding `*_STREAM_AVAILABLE` flags stay `False`.
