Each `.yaml` file is a self-contained 'skill' describing one trading approach (e.g., bottom_volume, event_driven, bull_trend). The system scans this directory and any additional directory set via `AGENT_SKILL_DIR`, loading all YAMLs into memory; later-defined or user-provided skills override built-in ones by `name`. Each skill declares metadata fields (`name`, `display_name`, `category`, `core_rules`, `required_tools`, `aliases`, `default_priority`, `market_regimes`) plus an `instructions` block written in natural language that guides an AI agent on which data tools to call (`get_daily_history`, `analyze_trend`, `get_realtime_quote`, `search_stock_news`, etc.) and how to adjust `sentiment_score` and populate `buy_reason`/`pattern_analysis`. There is no executable code in this module — it is pure configuration consumed by the surrounding agent/runtime that parses these YAMLs and executes the described logic.
