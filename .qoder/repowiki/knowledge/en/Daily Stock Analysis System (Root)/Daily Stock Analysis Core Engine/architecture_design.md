The `src/` package is organized as layered domains with clear one-way dependencies: `schemas/` defines the immutable data contracts (analysis context packs, decision profiles, market structure) consumed by every higher layer; `repositories/` provides SQLite-backed persistence for alerts, decisions, portfolios, and stock data used by services; `core/` holds domain primitives (trading calendar, market profile, pipeline, backtest engine); `llm/` abstracts generation backends via a registry/factory so agents and services can request completions without knowing provider details; `agent/` composes LLM calls into multi-agent workflows (decision, intel, portfolio, risk, technical) driven by an orchestrator and executor; `services/` exposes business use-cases (screening, alerting, history, portfolio, market light, skill-opinion performance) that orchestrate agents, repositories, and core engines; `notification_sender/` implements pluggable channels registered through `notification.py` routing. Top-level files (`config.py`, `scheduler.py`, `storage.py`, `auth.py`, `market_analyzer.py`, `stock_analyzer.py`) bootstrap the runtime, load configuration, schedule periodic tasks, and expose the public API that ties all children together.
