The module is a flat collection of Claude Code skill definitions under `.claude/skills/`, each skill living in its own directory with a single `SKILL.md` instruction file. Three skills are defined: `analyze-issue` (triage a GitHub issue into validity, scope, priority and recommendation), `analyze-pr` (evaluate PR completeness, CI status, diff and risk before merge), and `fix-issue` (implement a fix based on a prior issue analysis). Each `SKILL.md` follows an identical internal structure — header with repository link, `/command` usage block, numbered steps, output document template, an `Allowed Auto-Actions` list (read-only / safe operations) and an `Actions Requiring Confirmation` list (write or mutating operations). The skills share a common dependency direction: they all reference the repo's root `AGENTS.md` as the single source of truth for coding and commit conventions, use the `gh` CLI to fetch issue/PR metadata and diffs, and persist artifacts under `.claude/reviews/{issues|prs}/`. There is no executable code; the module is purely declarative instructions consumed by Claude Code when invoked via slash commands.
